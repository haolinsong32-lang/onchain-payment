# AI编程效率提示词工具包 - 使用指南

## 如何使用

每条 Prompt 采用「角色 + 任务 + 输出格式」结构化设计，复制后粘贴到 ChatGPT / Claude / Cursor / Copilot 即可使用。

### 基本用法
1. 打开你要用的 AI 工具（ChatGPT、Claude、Cursor 等）
2. 找到对应场景的 Prompt，点击「复制」
3. 粘贴到输入框，按实际需求微调（项目名、字段名、参数等）
4. 发送，AI 会按结构化要求输出高质量结果

### 提示词结构说明
- 【角色】：告诉 AI 它是什么专家，激活对应领域知识
- 【任务】：明确、可执行的具体需求，含约束条件
- 【输出格式】：规定输出形态（完整代码 / 分文件 / 带注释等）

### 微调技巧
- 把 Prompt 中的示例字段替换成你的真实字段
- 复杂任务可分步：先让 AI 给方案，再让它实现
- 不满意就继续追问，AI 会按你的反馈迭代
